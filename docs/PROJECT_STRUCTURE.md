`app/layout.tsx`\n\n### Auth levels\n\n- **Public**: No authentication required. CDN-cacheable where indicated. Some public endpoints require HMAC signature verification (badges, webhooks).\n- **Authenticated**: Requires a valid GitHub OAuth session (session cookie or JWT).\n- **Maintainer**: Requires `isMaintainer` flag in session (org member of `GITHUB_MAINTAINER_ORG`).\n- **Operator**: Requires `requireOperator` session (super-user for admin ops like API key management, metrics).\n- **Admin**: Special elevated access for webhook replay and system administration.\n\n### Dynamic route segments\n\n- `/api/profile/[username]` — dynamic segment in bracket notation (public profile endpoint)\n- `/api/badge/[username]` — dynamic segment in bracket notation (badge SVG with HMAC signature)\n\n### Webhook routes include replay subpath\n\n- `POST /api/webhooks/github-org-membership/replay` — admin replay endpoint (skips signature verification when `GITHUB_WEBHOOK_SECRET` is unset, requires admin session)\n- `POST /api/webhooks/trustbridge-action/replay` — admin replay endpoint (implicit, same handler with admin auth)\n- `POST /api/webhooks/github-org-membership` — main webhook endpoint (public, verifies signature)\n\n### Deprecated routes marked as removed\n\n- `/api/contributors` (old non-paginated endpoint — replaced by `/api/contributors/paginated`)\n- `/api/actions/lookup` (legacy implementation — new implementation at `app/api/actions/lookup/route.ts`)\n- `/api/registrations` (old bulk endpoint — now scoped to `/api/registrations/[id]` for maintainer ops)\n\n---\n\n## `src/components/` — UI\n\n```\ncomponents/\n├── ui/                      #
